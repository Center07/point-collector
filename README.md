# Point Collector

A simple points tracker, hosted free on GitHub Pages:
**https://center07.github.io/point-collector/**

- Current total: **7,100 points**, goal **13,400**
- Earns **260 a day** (or **1,000 every 2 days**) — the app shows the days left and the goal date
- Progress bar, quick-add buttons (+260 / +1,000), tap Edit total to fix the number
- Add point collectors and see who has the most (the top one gets the gold TOP badge)

Numbers are saved on the device (localStorage). The tracker uses the numbers Nirmal gives it — it can't see his points live anywhere.
